# Roadmap 4 — Technical Studio Visual System

Goal: convert the mature editor into one coherent professional desktop creative-tool interface without introducing new product functionality.

Canonical visual specification: `TECHNICAL_STUDIO_DESIGN.md`

Execution order:

1. V00 — Design Foundation
2. V01 — Core Controls
3. V02 — Workspace Chrome
4. V03 — Color Workspace Redesign
5. V04 — Right Inspector + 3D
6. V05 — Library + Document UX
7. V06 — Editor Interaction Surfaces
8. V07 — Technical Studio Quality Pass
9. STOP

## Dependency logic

V00 defines tokens, typography, spacing, surfaces, state primitives.
V01 applies them to reusable controls.
V02 brings overall shell/chrome into the system.
V03 gives the completed Color Workspace its final artist-oriented presentation.
V04 brings structure/history/3D into the same language.
V05 refines compact Library and documents.
V06 normalizes selection/UV/symmetry/semantic visuals.
V07 performs final consistency/accessibility/responsive audit and stops.

## Product boundary

No new product functionality. Preserve completed Roadmap 1–3 behavior and the post-Roadmap-3 Color Workspace foundation.

Explicitly excluded: AI, semantic palettes, ramps, palette generation, palette-to-skin mapping, browser/NameMC, community/social, cloud, plugins, marketplace.
