# Roadmap 2 — MCSkin3D Professional Editor Parity

## Goal

Reach practical modern artist-feature parity with MCSkin3D before beginning original AI/community functionality.

## Stages

```text
P00 — 3D Picking Foundation
P01 — Direct 3D Painting
P02 — Body Parts + Layer Visibility
P03 — Primary / Secondary Color
P04 — Advanced Color Controls + Swatches
P05 — Advanced Paint Tools
P06 — Tool Options System
P07 — History Timeline
P08 — New Skin + Drag-and-Drop
P09 — Local Skin Library / Multi-document
P10 — Pop-out Preview + Screenshot
P11 — MCSkin3D Parity Audit
STOP
```

The stage order is static and strictly sequential. Individual prompt files are also static and must be supplied and reviewed separately before execution.

## Explicitly out of scope unless required for parity

- AI
- semantic smart palettes
- reference intelligence
- browser
- NameMC integration
- community/social
- cloud accounts
- plugins
- marketplace

Roadmap objectives are static. Completion of P11 stops this loop by design; it does not create P12 or begin AI work automatically.
